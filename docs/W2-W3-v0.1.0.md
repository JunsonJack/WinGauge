## 一、交付清单

### 核心库 `wingauge-core`

| 模块 | 职责 |
|---|---|
| `collector` | sysinfo 实时采集：设备头 / CPU 每核 / 内存（含已提交）/ 主网卡速率 / 系统盘 |
| `validity` | 温度物理范围、`max==temp`、flatline 拦截 |
| `score` | 健康度 100 起扣 + 扣分明细 |
| `provider` | 能力抽象；通用温度固定 `Unavailable` |
| `snapshot` | 前后端共用指标模型（camelCase） |

单测：8 passed。冒烟：`cargo run -p wingauge-core --example smoke_tick` → `SMOKE OK`。

### 桌面壳 `src-tauri`

- `sampler`：后台 1s 采样线程，`snapshot://tick` 推送；面板隐藏时 2s，不停采
- 托盘「暂停采样」与设置页/命令双向同步
- IPC 命令：`get_autostart` / `set_autostart` / `app_version` / `quit_app` / `get_sampler_paused` / `set_sampler_paused`

### 前端 `frontend`

- 设备头、健康度卡（可展开扣分）、CPU 每核柱 + 趋势、内存进度条 + 趋势、网络速率 + 趋势、磁盘容量
- 设置页：开机自启开关、采样说明、隐私说明、退出
- 头栏：钉住 + 设置；Esc 先关设置再收面板

### 打包产物

```
target/release/bundle/nsis/WinGauge_0.1.0_x64-setup.exe
target/release/bundle/msi/WinGauge_0.1.0_x64_en-US.msi
```

Release 二进制：`target/release/app.exe`（编译 4m39s，0 error）。

## 四、已知遗留

1. **bundle identifier 为 `com.wingauge.app`**，Tauri 提示 macOS 下 `.app` 后缀不推荐；本产品仅 Windows，v0.1 不改（改了要重编译）。发布前建议改为 `com.wingauge.desktop`。
2. **UAC 普通权限复测**（W0 R10）仍未在另一台机器完成。
3. 网络主接口在虚拟网卡流量很大时可能选错；设置页手动选接口未做。
4. 磁盘 SMART / 盘温未接（W0：单次 3s，需低频缓存）。
